# Production hardening

TrueFace now includes account/RBAC controls, API keys, rate limiting, structured logs, metrics, optional Sentry, model/experiment registry, admin audit export and managed-PostgreSQL support through `DATABASE_URL`.

`POST /api/benchmark` calculates APCER, BPCER and ACER from documented bona-fide and attack scores and returns a threshold sweep. The repository intentionally does not publish benchmark claims until a representative PAD dataset is actually evaluated. The CNN endpoint remains optional and requires separately trained weights.

This remains a portfolio security prototype, not certified biometric authentication or ISO/IEC 30107 PAD compliance.
